## Final Readiness Statement

The system is **ready for submission** with the following conditions:

- **With API key configured**: The pipeline produces structured, explainable predictions with automatic Gemini → OpenRouter fallback. Expected to achieve strong accuracy on the leaderboard once the VLM is active.
- **Without API key**: The pipeline runs cleanly in preflight-only mode. All outputs are `NOT_ENOUGH_INFORMATION` (correct conservative default). Tests pass at 122/122.

---

## Known Gaps

1. **Rate limits at scale**: Free-tier Gemini (5 req/min) means a 34-row test set takes ~7 minutes. The benchmark cache mitigates this for repeated runs, but first-run latency remains high without a paid API tier or OpenRouter fallback.

2. **Object confusion on unusual angles**: The v4 prompt asks the VLM to identify the object type first, but extreme angles or close-up damage shots may still fail the `object_present` check. A future fix is to run a two-pass analysis: first identify the object, then zoom in on the damage.

3. **CSV missing-column error handling**: If `claims.csv` has missing columns, the error propagates as an uncaught exception in `CsvService`. A try/except with a user-friendly message would improve production readiness.

4. **Benchmark `--version both` is slow**: Running both v2 and v3 on 34 rows takes ~15 minutes on free tier. The default is now `--version v3` (single version) to reduce benchmark time.

5. **No integration tests against the real API**: The test suite (122 tests) uses mocked model services. A real-API smoke test is not included to avoid consuming API quota during CI.
